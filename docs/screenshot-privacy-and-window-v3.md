# 截图窗口排除、隐私和媒体保存设置

这些开关分别存储、默认关闭，启用某一项不要求开启其他新增项。已有隐藏状态栏、叠加层、小窗及录屏保存到 Movies 功能保留。适用范围受目标 ROM 的私有 API 限制，host 测试不能替代完整构建与真机验证。

| 入口 | 设置 | 作用与限制 |
| --- | --- | --- |
| 系统界面 → 状态栏 | 截屏时隐藏状态栏 / 叠加层 / 小窗 | 原有三项保留；窗口排除通过 WMS 的截图捕获链处理，修复捕获层级和已有排除层合并，保留 pin 小窗路径。 |
| 系统界面 → 状态栏 | 截屏时隐藏超级岛 | 新增独立开关，只排除符合窗口类型、精确标题、包名与所属 UID 的岛窗口；不依赖隐藏状态栏，不改变实时窗口显示和录屏。 |
| 系统框架 → 其他 → 屏幕 | 屏蔽应用截屏检测回调 | 仅 SDK 37、HyperOS 4，阻止 Activity.ScreenCaptureCallback 分发；截图保存、系统通知、媒体监听、录屏检测和 FLAG_SECURE 行为不由此改变。 |
| 系统框架 → 其他 → 屏幕 | 拦截媒体库变化通知 | SDK 37+、HyperOS 4，系统范围对所有应用和用户抑制 media ContentObserver 通知，包含图片、音频、视频、files 与根 URI。图库可能不自动刷新；媒体记录仍可查询。 |
| 系统界面 → 其他 | 原生截图保存到 Pictures/xml | SDK 37+、HyperOS 4，只修改新建原生 SystemUI 截图的媒体库保存路径，不移动历史文件，不覆盖 MIUI、副屏和自定义目标导出。 |
| 系统界面 → 其他 | 截图文件名去除 Screenshot_ 前缀 | 独立于保存路径，仅精确移除一次开头前缀，保留时间戳、唯一后缀与扩展名。 |
| 屏幕录制 | 新录屏保存至 Pictures/xml | SDK 37+、HyperOS 4，覆盖匹配 ROM 的 MIUI 与原生 SystemUI 录屏保存链；启用时优先于保存至 Movies。 |
| 屏幕录制 | 录屏文件名去除产品前缀 | 独立于保存路径，仅移除一次精确开头 Screenrecorder_、Screenrecorder- 或 screen-，保留其余文件名。 |

窗口排除在 SDK 37+ 的系统框架中装载，需要在框架管理器选择 Android 系统框架作用域；修改后重启相关系统进程，建议用户自行择时重启设备。SystemUI 保存设置需系统界面作用域，MIUI 录屏保存设置需屏幕录制作用域；修改后重启对应进程。窗口排除保留原始 excludeLayers，按截图调用嵌套作用域追踪并释放 SurfaceControl 副本；不匹配目标或发生排除异常时保留截图链原有行为。

所有新文件保存设置仅影响之后产生的媒体，不迁移历史文件。拦截通知与回调不保证应用无法通过主动查询、其他监听或自身机制判断截图；媒体通知拦截具有系统范围的自动刷新副作用，应按需要单独开启。

测试入口为 `python3 -B tests/screenshot-window-v3/run_all.py`，详细前提与覆盖范围见该目录 README。测试编译当前 checkout 的真实生产 Hook，Android、WMS、BaseHook 和 SurfaceControl 使用明确有界 fixture；不执行设备操作、不携带反编译 ROM、不代表 APK 已构建或真机像素验证成功。

熄屏相机是另一项默认关闭的独立设置，详见 [熄屏双击音量下拍照](screen-off-camera.md)。
